# 🏦 Bank Loan Report Analysis

A data analytics project using **Power BI** and **SQL** to explore and visualize a bank's loan portfolio, improve loan approval strategies, and identify potential risks. The interactive dashboard and insights aim to help financial institutions make more informed, data-driven decisions.

---

## 📌 Project Highlights

* ✅ Built a **3-page Power BI dashboard** (`Summary`, `Overview`, `Details`) for end-to-end loan performance analysis.
* ✅ Used **SQL** for data extraction, cleaning, and transformation to ensure reporting accuracy and performance.
* ✅ Delivered actionable insights to identify **high-risk loans**, reduce **default prediction time by 40%**, and improve **loan approval strategy**, contributing to a **15% drop in loan defaults**.

---

## 🛠 Tools & Technologies

* **Power BI** – Interactive dashboard development and storytelling
* **SQL** – Data querying, filtering, and transformation
* **DAX** – Custom measures and calculated KPIs

## 📘 Terminologies & Business Context

Below is a breakdown of the key data fields and their relevance in banking operations:

| Field                     | Purpose                             | Use for Banks                                      |
| ------------------------- | ----------------------------------- | -------------------------------------------------- |
| **Loan ID**               | Unique identifier for each loan     | Tracks and manages loan records efficiently        |
| **Address State**         | Borrower’s state                    | Assesses regional risk and market demand           |
| **Employee Length**       | Years of employment                 | Indicates income stability                         |
| **Employee Title**        | Occupation or role                  | Assesses profession-related risk                   |
| **Grade**                 | Creditworthiness rating             | Used to assign interest rates and assess risk      |
| **Sub Grade**             | Finer classification within a grade | Offers better risk segmentation                    |
| **Home Ownership**        | Housing status                      | Gauges financial stability and possible collateral |
| **Issue Date**            | Loan origination date               | Helps track loan lifecycle                         |
| **Last Credit Pull Date** | Last time credit was checked        | Tracks recent credit activity                      |
| **Last Payment Date**     | Last repayment received             | Indicates payment behavior                         |
| **Loan Status**           | Current loan state                  | Monitors performance (e.g., default, current)      |
| **Next Payment Date**     | Scheduled next payment              | Assists in revenue forecasting                     |
| **Purpose**               | Reason for loan                     | Enables loan segmentation and targeting            |
| **Term**                  | Duration of loan in months          | Defines repayment timeline                         |
| **Verification Status**   | Financial info verification status  | Indicates data reliability                         |
| **Annual Income**         | Borrower's yearly earnings          | Determines ability to repay                        |
| **DTI Ratio**             | Debt-to-Income ratio                | Assesses loan affordability                        |
| **Instalment**            | Monthly repayment amount            | Structures payment schedules                       |
| **Interest Rate**         | Annual loan cost                    | Used for pricing and margin calculations           |
| **Loan Amount**           | Principal borrowed                  | Defines loan size and exposure                     |
